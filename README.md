# EquityLens One V6

A showcase-quality Streamlit stock and IPO research command center.

## Deploy
Upload `app.py`, `requirements.txt`, and `.streamlit/config.toml` to the root of the existing GitHub repository. Streamlit Cloud redeploys automatically.

## Data modes
- Live price / statements where the public feed succeeds.
- Bundled fallback fundamentals for selected showcase symbols.
- Clearly labelled showcase IPO dataset until an authorised live IPO feed is connected.

This avoids blank dashboards and misleading hidden failures.
